Selected work

theia Rust · P2P overlay + services

A public-key-addressed, control-plane-free peer-to-peer overlay I architected and built solo. Reach any machine by its ed25519 identity, across NATs, with no address, account, or server in between. I generalized the transport behind a single trait: it runs on iroh or on a QUIC-style UDP transport I wrote from scratch, proven substitutable under one conformance suite that ships decoy transports, so it can't pass by accident. On top: keyless SSH, file transfer, and link measurement, all behind one CLI.

  • bifrost: the transport substrate. One trait every transport implements (iroh, or my from-scratch QUIC-style UDP), kept honest by a conformance suite that ships decoy transports so it can't pass vacuously. Where it's going: encryption as a composable Noise layer over any transport, and more "radios" under one trait.
  • nauthy: capability auth where the key is the identity. Offline-verifiable against a single held key, no coordinator; attenuable, expiring, revocable; a single-use admission witness with compile-time replay-safety.
  • tightbeam: a capability-gated stream aimed at exactly one public key. A nauthy capability opens a directed tunnel to one peer, nothing broadcast.
  • swoosh: one CLI for everything the overlay can do, under a single beam verb.

Approach
